# 小球擂台维护要求

遵守根目录 AGENTS.md。保留原作来源与 Kizu_Na 致谢；新增代码位于 web/，不要把旧平台外壳、统计、跳转或 SDK 带入。

- 主界面为默认入口，自由对战与锦标赛分开进入；游戏内只返回主界面，不增加回大厅链接。版本为 1.0.1。
- 锦标赛沿用原作精英占两个名额、角色不重复的规则；4–128 强按 2 的幂选择，容量不足须置灰，不静默缩小。平局重赛，不任意指定胜者。保存赛程但不保存中途对战，重放不改赛果。
- 选人页面为视口内布局，只有角色目录滚动；阵容、搜索筛选及开战操作始终可达。多人模式不得用省略整队的方式掩盖布局问题。
- 保留 184 个原角色定义，新增角色通过 registerBall 注册；机制标签在 web/tags.js 独立维护。
- 固定 1/60 秒推进；渲染、预览、音效和 UI 不消耗对局随机流。机关在同一固定步中以世界时间推进。
- 以既有伤害、效果与碰撞服务处理角色交互；机关不能绕开原防御，也不能命中候场、死亡、隐藏或不可交互角色。
- 同种子重放必须重建所有状态，不能重复计入系列赛。返回选人保留目录位置、阵容与筛选；调整窗口不重开对局。
- 本游戏独立打开，不依赖原站。保存采用 ball-arena-settings-v1，禁止清除其他游戏存储，不注册 Service Worker。
- 验证：README 中的逻辑、浏览器和大厅命令。浏览器尺寸为 1920×1080、1440×900、1280×720、960×540、844×390、390×844；检查真实截图，特别是矮屏完整卡片、六人阵容和手机筛选。截图及测试输出放临时目录或 test-output/。

- 场上红蓝阵营环必须与血条一致，不能用角色本色推断阵营；召唤物跟随实际归属。自由混战不使用红蓝队伍标识，目录预览不显示阵营环。
