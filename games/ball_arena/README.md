# 小球擂台 · 1.0.1

190 个角色的自动对战沙盒。角色目录独立滚动，双方阵容和开战按钮始终可见。主界面提供自由对战和锦标赛入口，自由对战的默认对阵为老木师 VS 钢卷。使用浏览器后退返回 Games 大厅，游戏内不放置回大厅按钮。

感谢原作者 **[Kizu_Na](https://space.bilibili.com/3546819271330077)** 创作《小球对战》。本作保留原作的战斗核心与 184 个角色，重做选人和观战界面，并新增 6 个角色、3 种场地机关及系列赛。详细来源见 [SOURCE.md](SOURCE.md)，游戏帮助中也有致谢与主页链接。

## 打开与操作

从 Games 大厅进入，或直接打开本目录的 `index.html`。本地服务：在仓库根目录运行 `npm run dev`，进入 `/games/ball_arena/`。代码、字体和绘制素材均在本目录，无需请求原站，也不注册离线 Worker。

先点阵容槽位，再点角色。支持名称／技能搜索、机制标签、收藏、双方交换、单队或全阵容随机。随机默认只抽普通角色，可在场地设置扩大范围；Boss 只能进入 Boss 挑战的红方槽位。

开战后纯自动观战。空格暂停／继续，Esc 关闭详情或暂停；暂停时可单步推进。支持 0.5、1、2、4 倍速；声音默认开启，可手动关闭并记住选择。浏览器会在首次点击或按键后允许声音播放。主界面每次进入会随机挑选两个不同的普通球演示，演示结束后自动更换对阵，不改变玩家阵容。窗口失焦自动暂停，不会自动恢复。

每局上限为 180 秒模拟推进时间（包含角色的时停演出），到时判平。双方面对战支持三局两胜、五局三胜；平局不计胜场，连续三次平局并列结束。每局重置生命并换新种子。“原种子重放”不会再次记分；“换种子再战”重新开始一场单局或系列赛。结算框关闭后可点底部的种子／结束状态重新查看结果。

## 锦标赛

直接复用原作移动端锦标赛模型，支持 4、8、16、32、64、128 球／队。1V1 每球独立参赛；2V2、3V3 按名额组队，精英占两个名额，普通球占一个名额，所有成员同时出战。

默认从普通与精英球抽签，保留原作禁用名单；可开启“过滤精英球”。同一角色不会重复进入不同队伍。角色不足的规模置灰并显示当前容量，不会抽签后偷偷缩小规模。当前参赛池可供 178 球、90 支二人规格队、60 支三人规格队；过滤精英后分别为 175、87、58。

抽签后锁定阵容和场地，单败淘汰，每场重新满血。按轮次查看赛程、观看待开始的比赛、重放已结束比赛；重放不会改变晋级结果。平局不晋级，换种子重赛，不按剩余血量强行判胜。比赛结果自动保存在独立存储键 ball-arena-tournament-v1，刷新后可继续赛程；未完成的场次使用原种子从头重开，不保存中途战斗画面。

返回赛程或主界面会暂停当前比赛；页面未关闭时可继续现场比赛。重新抽签需在游戏内确认，以免误清空本届进度。

## 模式与新增内容

- 单挑：一对一。
- 团战：双方各 1–6 人，同时入场。
- 车轮战：双方各 1–6 人，依次入场，胜者保留生命。
- 自由混战：2–12 人，各自为战，仅单局。
- Boss 挑战：红方原作 Boss 对抗蓝方 1–6 位挑战者。使用原核心 totalwar 模式，不额外乘十倍生命。

弹跳、陀螺物理仅在支持的普通场地开放。三种机关默认关闭，可分别开启：四个对称弹射垫、每 10 秒产生且最多两个的急救补给、每 12 秒预警后横纵交替扫射的激光。补给回复 12 点生命；激光每次扫射对每个角色最多造成一次 8 点普通伤害，遵守原有防御。机关使用世界模拟时间，因此随全局时停停止，不随画面帧数变化。

原创角色均为生命 100、速度 150、半径 15：

| 角色 | 机制 |
| --- | --- |
| 弹簧拳 | 每 3 秒发射短程拳，造成 6 点伤害并击退 |
| 油漆匠 | 每 2 秒留下一片持续 6 秒的油漆，区域减速 25%，同源不叠加，最多 6 区 |
| 快递员 | 每 5 秒锁定最近敌人当前位置，1 秒预警后爆炸造成 10 点范围伤害 |
| 回旋镖 | 每 4 秒发射，去程和回程对同一敌人各造成一次 4 点伤害 |
| 泡泡机 | 每 3 秒发射，造成 2 点伤害，减速 40% 持续 1.5 秒 |
| 蓄电池 | 实际受伤的 30% 储存为电量，上限 20，每 5 秒对 65 范围内敌人放电，未命中保留电量 |

浏览器保存收藏、设置和最近阵容；不保存中途对局。存储被禁用时仍可正常玩。

## 维护与验证

- `src/`：原核心、原角色及必要素材。原文件保留注释与声明。
- `web/`：新界面、配置与系列赛模型、原创角色、机关；`tags.js` 是独立维护的机制标签数据。
- `tests/`：角色元数据基线、独立加载器、逻辑及真实浏览器验证。

在仓库根目录运行：

```sh
node --test games/ball_arena/tests/*.test.cjs
python3 games/ball_arena/tests/browser.py
python3 games/ball_arena/tests/tournament_browser.py
npm run check
npm test
npm run test:browser
```

浏览器验证需要 Python Playwright 与 Chromium；可通过 `PLAYWRIGHT_BROWSERS_PATH` 指定测试浏览器目录。截图默认写入系统临时目录 `ball-arena-checks`。覆盖根路径与 `/Games/` 子路径、六种窗口、连续缩放、完整选人和观战操作、系列赛、180 秒平局、重放、触屏和禁用存储。
