# 小球擂台 · 1.0.4

190 个角色的自动对战沙盒。角色目录独立滚动，双方阵容和开战按钮始终可见。主界面提供自由对战和锦标赛入口，自由对战的默认对阵为老木师 VS 钢卷。使用浏览器后退返回 Games 大厅，游戏内不放置回大厅按钮。

感谢原作者 **[Kizu_Na](https://space.bilibili.com/3546819271330077)** 创作《小球对战》。本作保留原作的战斗核心与 184 个角色，重做选人和观战界面，并新增 6 个角色、3 种场地机关及系列赛。详细来源见 [SOURCE.md](SOURCE.md)，游戏帮助中也有致谢与主页链接。

## 打开与操作

从 Games 大厅进入，或直接打开本目录的 `index.html`。本地服务：在仓库根目录运行 `npm run dev`，进入 `/games/ball_arena/`。代码、字体和绘制素材均在本目录，无需请求原站，也不注册离线 Worker。

先点阵容槽位，再点角色。支持名称／技能搜索、机制标签、收藏、双方交换、单队或全阵容随机。随机默认只抽普通角色，可在顶部勾选“随机选人包含特殊角色”，让“随机对阵”和双方的“随机”额外选到杂鱼、精英、规格外角色（不影响手动选人或锦标赛抽签）；Boss 只能进入 Boss 挑战的红方槽位。

开战后纯自动观战。空格暂停／继续，Esc 关闭详情或暂停；暂停时可单步推进。对局中点红蓝血条中间的“角色技能”可查看本场双方全部角色的机制：打开时自动暂停，关闭后继续；如果打开前已手动暂停，关闭后保持暂停。支持 0.5、1、2、4 倍速；声音默认开启，可手动关闭并记住选择。浏览器会在首次点击或按键后允许声音播放。主界面每次进入会随机挑选两个不同的普通球演示，演示结束后自动更换对阵，不改变玩家阵容。窗口失焦自动暂停，不会自动恢复。

每局的模拟时间上限按模式区分（包含角色的时停演出）：单挑 4:00，团战 6:00，车轮战 10:00，自由混战 8:00，Boss 挑战 8:00。到时按剩余总生命判定，剩余总生命更多的一方获胜；总生命相同才判平。双方面对战支持三局两胜、五局三胜；平局不计胜场，连续三次平局并列结束。每局重置生命并换新种子。“原种子重放”不会再次记分；“换种子再战”重新开始一场单局或系列赛。结算框关闭后可点底部的种子／结束状态重新查看结果。

## 锦标赛

直接复用原作移动端锦标赛模型，支持 4、8、16、32、64、128 球／队。1V1 每球独立参赛；2V2、3V3 按名额组队，精英占两个名额，普通球占一个名额，同时上场模式所有成员同时出战。车轮战支持每队 2–6 个名额（精英占两个），按抽签顺序依次入场，胜者保留生命；每场限时 10 分钟，下一场全队重新满血。四／五／六名额可组 45／36／30 队，过滤精英后为 43／35／29 队。

默认从普通与精英球抽签，保留原作禁用名单；可开启“过滤精英球”。同一角色不会重复进入不同队伍。角色不足的规模置灰并显示当前容量，不会抽签后偷偷缩小规模。当前参赛池可供 178 球、90 支二人规格队、60 支三人规格队；过滤精英后分别为 175、87、58。

抽签后锁定阵容和场地，单败淘汰，每场重新满血。按轮次查看赛程、观看待开始的比赛、重放已结束比赛；重放不会改变晋级结果。限时结束时按剩余总生命判定，只有总生命相同才平局；平局不晋级并换种子重赛，不任意指定胜者。比赛结果自动保存在独立存储键 ball-arena-tournament-v1，刷新后可继续赛程；未完成的场次使用原种子从头重开，不保存中途战斗画面。

返回赛程或主界面会暂停当前正式比赛，页面未关闭时可继续现场比赛；重放是独立会话，退出即结束，不会占用“继续当前比赛”。重新抽签需在游戏内确认，以免误清空本届进度。

## 模式与新增内容

- 单挑：一对一。
- 团战：双方各 1–6 人，同时入场。
- 车轮战：双方各 1–6 人，依次入场，胜者保留生命。
- 自由混战：2–12 人，各自为战，仅单局。
- Boss 挑战：红方原作 Boss 对抗蓝方 1–6 位挑战者。使用原核心 totalwar 模式，不额外乘十倍生命。

弹跳、陀螺物理仅在支持的普通场地开放。三种机关默认关闭，可分别开启：四个对称弹射垫、每 10 秒产生且最多两个的急救补给、每 12 秒预警后横纵交替扫射的激光。补给回复 12 点生命；激光每次扫射对每个角色最多造成一次 8 点普通伤害，遵守原有防御。机关使用世界模拟时间，因此随全局时停停止，不随画面帧数变化。

原创角色均为生命 100、速度 150、半径 15：

| 角色 | 机制 |
| --- | --- |
| 弹簧拳 | 撞墙压缩弹簧，最多 3 层；接触敌人造成 4+2×层数伤害并击退；满 3 层眩晕；高压时减伤 |
| 油漆匠 | 移动滴落油漆、撞墙刷漆线；区域减速 35% 并持续伤害；最多 6 池、4 条线 |
| 快递员 | 快递箱绕身旋转；敌人碰到受 7 点伤害并减速；箱子回收时回复 1 点、短暂加速并产生余波 |
| 回旋镖 | 一次投出两枚回旋镖，碰墙反弹最多 3 次；每个敌人每 0.5 秒最多受一次 3 点伤害 |
| 泡泡机 | 周期进入无敌泡泡形态；破裂时 55 范围 5 点伤害并留下减速、持续伤害的泡沫区域 |
| 蓄电池 | 受伤或撞墙蓄电，最多 4 层；接触敌人造成 2+2×电量伤害；满电自动放电并眩晕周围 |

数值参照同类角色：弹簧拳参考锯球V2/足球/拳击手，油漆匠参考岩浆球/荆棘，快递员参考陷阱师/果冻/装甲，回旋镖参考图钉/碎片，泡泡机参考花粉/果冻，蓄电池参考电荷/电球V2。

浏览器保存收藏、设置和最近阵容；不保存中途对局。存储被禁用时仍可正常玩。

## 维护与验证

- `src/`：原核心、原角色及必要素材。原文件保留注释与声明。
- `web/`：新界面、配置与系列赛模型、原创角色、机关；`tags.js` 是独立维护的机制标签数据，`descriptions.js` 是独立维护的清晰化角色介绍。
- `tests/`：角色元数据基线、独立加载器、逻辑及真实浏览器验证。

在仓库根目录运行：

```sh
node --test games/ball_arena/tests/*.test.cjs
python3 games/ball_arena/tests/browser.py
python3 games/ball_arena/tests/tournament_browser.py
npm run check
npm test
npm run test:browser
```

浏览器验证需要 Python Playwright 与 Chromium；可通过 `PLAYWRIGHT_BROWSERS_PATH` 指定测试浏览器目录。截图默认写入系统临时目录 `ball-arena-checks`。覆盖根路径与 `/Games/` 子路径、六种窗口、连续缩放、完整选人和观战操作、对局技能面板的自动暂停／继续、各模式限时与血量判定、系列赛、重放、触屏和禁用存储。
