# WAR LAB · 战争沙盘

双击 `index.html` 即可运行，无需安装、构建或联网。原生 Canvas 2D 与经典 JavaScript 脚本，保留 file:// 支持。

## 主界面与模式

启动后先选择征途闯关、自由沙盘或战役实验，再在主界面选择关卡、规则或预设。自由沙盘从空白战场开始。进入战场后，左侧栏分页选择兵种；“部署工具”按布阵、兵种、存档分组。闯关中不能保存或读取自由布阵。

“主界面”会挂起当前战场，使用“继续当前战场”可恢复原布阵和战斗状态。主界面调整设置后若选择继续，会保留原战场规则；点击进入新战场才会替换当前对局。

## 玩法

- 20 种兵种，左半场红军、右半场蓝军。点击或拖动部署；右键或橡皮擦删除。
- 四组战役：均衡交锋、巨人与蜂群、盾墙与箭雨、奥术混战。
- 单兵、五人纵列、六人锋矢、九人方阵；撤销部署与本机布阵保存/读取。
- 歼灭战：消灭敌军，180 秒未分胜负按剩余生命比例结算。
- 据点争夺：中央据点无敌方占据时持续得分，30 分获胜。歼灭敌军也可获胜；180 秒按积分结算。
- 风暴决战：10 秒后安全圈逐渐收缩，圈外持续受伤。
- 暂停、四分之一速慢动作、原阵容再战。随机配兵会替换当前阵容。
- 全景、缩放按钮、移动镜头工具适用于触屏。桌面支持滚轮与 WASD / 方向键。
- 空格暂停，M 慢动作，R 重置，G 网格，Tab 开战。

## 征途闯关

主界面“征途闯关”选择关卡并进入。八关包含歼灭、据点、风暴任务；你指挥红军，敌军固定，红军有预算限制。每关提供可调整的参考阵容，清空只移除红军，删除士兵返还预算。胜利解锁下一关，最佳星级保存到当前浏览器。

三星条件相互独立：获胜一星；至少半数出战单位存活再一星；部署花费不超过预算 85% 再一星。物理战斗有随机性，参考阵容不保证必胜。

## 新兵种与物理

- 疾风枪骑：有冷却的冲锋和碰撞伤害，长戟正面架枪可反制。
- 震地重锤：范围击退与短暂震慑，重武器有更大摆动惯性。
- 游刃剑客：侧向突进，短时减伤，轻质量易被击退。
- 霜语术士：命中减速，影响移速、转身及主动旋转。
- 重型弩炮：发射后坐力，最多贯穿三个目标，伤害逐次衰减。
- 炼金投弹手：慢速、大范围爆弹，适合对付密集阵型。
- 军旗卫士：附近友军增伤、加速，光环不叠加，阵亡失效。
- 铁壁长戟：正面反冲锋，转身有限，需要保护侧翼。

不同质量影响起步、击退和恢复；重甲碰撞更不易弹飞；近战伤害随接触速度有限变化；拼刀使用武器惯量与本体质量，并限制极端冲量。保持俯视平面物理，不模拟垂直腾空。

## 交互

搜索框支持兵种名称和能力关键词。选择 / 移动工具用于查看单位与拖动调位；拖动不可越界、跨阵营或重叠。战斗中点击单位查看生命、技能冷却与状态。Delete 删除选中单位，Escape 取消选择，Ctrl/Cmd + Z 撤销。阵型部署时预览额外落点，红圈提示冲突。

## 文件

- `index.html`：页面结构与加载入口，无内联 CSS / JavaScript。
- `css/style.css`：战术沙盘主题及窄屏、横屏、超宽屏布局。
- `js/`：配置、物理、AI、渲染、交互与战役逻辑；`lab.js` 管理实验玩法，`roster.js` / `abilities.js` 管理扩展兵种与技能，`campaign.js` 管理关卡，`interaction.js` 管理选择与调位。
- `tests/simulation.cjs`：运行 `node tests/simulation.cjs` 验证真实游戏模块的布阵、结算、风暴与完整模拟。

- `tests/startup.cjs`：运行 `node tests/startup.cjs` 检查完整入口加载、按钮、调位和绘制 API 调用（使用 DOM/Canvas 桩，不代表浏览器视觉验收）。

## 验证范围

逻辑集成测试及所有脚本语法检查已通过；包括三种模式、八关完整对局、技能效果、预算、敌军锁定、解锁与进度保存。已使用真实 Chromium 验证 1920×1080、1440×900、1280×720、960×540、844×390、390×844，覆盖模式选择、二十兵种分页与搜索、工具分组、窗口变化后的部署坐标及暂停恢复。

## 玩具兵界面

红蓝棋子、旗标模式入口与侧边兵种栏组成桌面沙盘。主页面按窗口宽高布局，不需要滚动。兵种详情按需展开，战斗时收起侧栏；画布随布局重新测量，布阵坐标保持一致。键盘仍可操作工具与分页。

运行 `python3 tests/layout_browser.py` 做窗口与交互回归；可用 `WAR_BROWSER_PATH` 指定现有 Chromium，`WAR_TEST_URL` 指定 HTTP 地址，默认直接检查本地 HTML。

## 地图与地形

地图各有比例与真实轮廓：草原为 1680×840（2:1），林地为八角形，湿地为扁长六边形，隘口中央收腰，林溪采用红蓝不对称的不规则多边形。自由沙盘和战役实验在进入前可选择开阔草原、疏林小径、浅滩湿地、碎石隘口、林溪交错；八个征途关卡保留开阔草原。

树林内移速为正常的 80%，浅水内为 60%；重叠时取较强减速，并与技能减速相乘。岩石阻挡士兵、近战和弹道；士兵按体型绕行，爆炸保留范围伤害。地图预览与说明在选择地图时显示。

HUD、地图画布与镜头工具分别占用空间，全景完整显示地图轮廓。左侧“兵种／布阵／存档”切换功能，窄竖屏用“部署栏”展开或收起，选择兵种后自动收起。长兵种详情可在侧栏内阅读。

布阵保存包含地图；旧布阵默认读取到草原，无效存档不会替换当前布阵。返回主界面后继续、重置和再战保留原地图。

运行 `node tests/terrain.cjs` 检查地形减速、障碍检测、体型寻路、随机布阵和真实障碍对局。

地图轮廓参与部署、单位碰撞、寻路和攻击阻挡，凹口外的空白区域不可通行。镜头和预览按各地图范围适配。
