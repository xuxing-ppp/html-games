# 生命游戏

直接双击本目录的 **index.html**，在现代桌面浏览器中打开即可离线游玩。无需安装依赖、本地服务器或联网；请保留 `web/` 文件夹。

## 模式与规则

- **经典生命**：支持自定义 B/S 规则及 Life、HighLife、Seeds、Maze 四种预设。B 指定出生所需的活邻居数，S 指定存活所需的活邻居数，默认 B3/S23。
- **Logistic 连续生命**：细胞状态 s 在 0–1 之间，m 为八邻域状态之和。稳定区间内保持 s；生长区间内按 `(1−λ)s+λ` 更新；其他位置按 `(1−λ)s` 衰减。区间重叠时生长优先。
- λ 在 0–1 之间，稳定和生长区间端点在 0–8 之间，均可在运行中调整。λ=0 冻结；默认区间且初始细胞为 0／1 时，λ=1 等同经典生命。
- 支持周期边界（四边相连）和开放边界（外侧为死区），地图行列数分别为 5–10000。

## 操作与保存

- 初始地图为空且暂停。左键绘制、右键擦除，拖动可连续操作；运行中也可编辑。
- 空格运行／暂停，N 暂停时单步；速度为 1–60 代／秒。C 清空，R 随机填充约 25%，B 切换边界，G 切换网格。
- 构型工具包含全部 13 个构型：Block、Boat、Blinker、Toad、Beacon、Pulsar、Pentadecathlon、Glider、LWSS、Glider Gun、R-pentomino、Acorn、Line。
- 选择构型后预览并点击盖章，可连续放置；←／→ 旋转，↑／↓ 翻转。右键、Esc 或再次选择当前构型退出图章模式。
- 非图章模式下方向键或 +／− 调整速度，连续模式中 [／] 调整 λ。输入框编辑时不会触发游戏快捷键。
- 滚轮围绕光标缩放，中键拖动平移；也可使用绘制／擦除／平移、缩放和全图按钮。小于一像素的细胞显示为密度总览。
- 返回主界面保留本次实验，可继续；设置会尽可能记忆在浏览器中。关闭页面前可通过“更多操作”导出 JSON 快照，保存细胞值、模式、规则参数、代数、速度和视口；导入后暂停。

大地图在后台分批计算，线程不可用时使用分批回退。10000×10000 的连续模式双缓冲约占 800 MB；计算较慢时实际代速下降，但不跳代。完整说明见游戏内帮助。

## 维护与验证

- `web/core.js`：规则解析、校验、演化和构型变换。
- `web/engine.js`：后台计算、快照和分批回退；`web/patterns.js` 保存构型数据。
- `web/render.js`：视口、密度绘制及主界面预览；`web/app.js`、`web/style.css` 负责交互与布局。
- 逻辑回归：在本项目目录执行 `node --test tests/*.test.cjs`。其中 `tests/fixtures/python-rules.json` 保存旧版实现的 16 组配置、各 8 代参考结果，测试对照不依赖 Python 或 NumPy。
- 浏览器回归：在 `html_games` 项目根目录执行 `python3 tests/html_games_browser.py` 或 `python3 tests/html_games_extended.py`，需要 Playwright 和 Chromium；可用 `PLAYWRIGHT_BROWSERS_PATH` 指定浏览器缓存。这些是开发测试工具，游戏运行不依赖 Python。

项目只维护 HTML／JavaScript 版本，旧 Python 实现及其依赖已移除。

## 显示版本

标题页与 Games 大厅共用本目录 `version.js`。修改时直接编辑引号内的版本数字。复制游戏时请一并保留此文件。版本维护方法见项目根目录的 [README.md](../../README.md)，显示版本与存档格式独立。
