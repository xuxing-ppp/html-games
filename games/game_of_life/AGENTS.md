# 生命游戏

本项目同时遵守项目根目录的 [AGENTS.md](../../AGENTS.md) 的通用要求。

- HTML 为默认入口，保留双击 index.html 离线运行，无服务器、联网或安装依赖。
- 保持米白实验台、墨绿细胞与培养皿风格。圆形培养皿仅用于主界面预览，实验网格保持完整矩形。
- 经典与 Logistic 连续生命共用入口；保留自定义 B/S 规则、两种边界、λ 及稳定／生长区间四端点。区间重叠时生长优先。
- 保留 5–10000 行列、1–60 代／秒、运行中编辑、缩放平移和全部 13 个原有构型（含 Line），支持图章旋转与翻转。
- 大地图在后台分批计算，线程不可用时回退到分批计算；保持控制界面响应，不通过跳代或缩小地图上限简化迁移。
- 保留带版本号的 JSON 实验快照导入／导出；连续细胞值不得丢失，导入后暂停，无效快照不得破坏当前实验。
- 规则改动运行 `node --test tests/*.test.cjs`；测试使用 `tests/fixtures/python-rules.json` 中保存的原版结果进行对照，无需 Python 或 NumPy。界面、离线和大地图改动按范围在 `html_games` 项目根目录运行两份 `tests/html_games_*.py` 并查看画面。
