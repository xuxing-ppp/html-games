# 街机赛车

基于本地 Three.js 的 3D 街机竞速游戏。十二条立体赛道，支持键盘、本地双人分屏、竞速大奖赛、单圈计时和90秒技巧挑战。无需构建或在线服务。

## 启动与关闭

Mac 上直接双击本文件夹里的 **“启动游戏.command”**，浏览器会自动打开游戏。玩完双击 **“关闭游戏.command”** 即可停止。

也可以在终端使用：

```sh
npm run dev    # 启动并自动打开游戏
npm run stop   # 关闭游戏，可在另一个终端窗口执行
```

启动窗口中按 **Control + C** 也能停止。只关闭浏览器标签页不会停止游戏服务。

重复启动会直接打开已经运行的游戏，不会再报“端口被占用”。如果默认地址被其他程序占用，会自动选择可用地址并打开，无须手动改端口。始终以启动窗口显示的地址为准。

无需构建或安装额外依赖；启动使用 Node.js（运行 npm 所需的环境）。请通过启动入口打开，不要直接双击 HTML。窄屏支持菜单浏览，驾驶仍使用键盘。

## 地形技巧竞速

- 漂移：按住漂移键并转向蓄能，松开释放三级短加速。下坡可积累高于平路巡航的速度，上坡前要保持速度。
- 飞跃：黄色箭头标识跳台，车辆自动起跳。空中左右微调落点；腾空后新按一次漂移键做特技，成功落地获得短加速。起跳前一直按住不会自动触发。
- 落地：对齐道路方向保留速度，偏斜落地短暂减速。成功特技180分、平稳落地60分，按当前倍率计算；同圈同一跳台不重复刷落地积分。加速时长取最大值，不无限叠加。
- 捷径：除阳光环道外，赛道都有黄色箭头标示的较窄分支，进入与汇合对应主路比赛进度。主路线更宽、更容易通过。
- 吸附道路：星际跑道包含完整竖直圆环与倒挂路段，青色路缘标识；自动吸附，无切换键或入场速度门槛，正常加速即可通过，仍可选线和超车。
- 救援：飞出高架、错过落点会短暂救援回当前路线的安全位置，损失时间；不会跳检查点或传送到另一层道路。

原有切相、电量、能量门和相应操作已删除。

## 模式与保存

竞速大奖赛：8车同场，默认3圈，可设置1–5圈及五档AI难度。保留蘑菇、香蕉、直线弹与追踪弹，三种调校、五种车漆、金币、路面加减速带。道具与碰撞按三维位置和道路层级判断。

计时挑战：无AI与道具，单圈计时，支持双人分别完赛。

技巧挑战：90秒内通过漂移、特技和平稳落地计分，连段倍率最高四倍，目标5000分。双人独立计分与反馈。

保留浏览器中累计金币、完赛次数和设置。历史纪录保留原值；新道路与计分采用 `terrain-v3:` 纪录前缀，不与旧纪录比较。天气仍仅影响视觉。设置可减少动态效果，并尊重系统减少动态效果偏好。

## 操作

| 功能 | 单人 | 双人P1 | 双人P2 |
| --- | --- | --- | --- |
| 加速／刹车 | ↑↓ 或 W/S | ↑↓ | W/S |
| 转向 | ←→ 或 A/D | ←→ | A/D |
| 地面漂移／空中特技 | 任意 Shift | 右 Shift | 左 Shift |
| 道具 | 空格／Enter | Enter | 空格 |

C切换追逐视角，Esc暂停，R重开，M静音。离开窗口或切换标签页自动暂停。调整窗口保留配置和比赛状态。

## 实现与验证

`src/world/course.js` 生成带连续路面朝向的三维道路和捷径，提供道路采样与局部三维投影；`src/world/driving.js` 实现贴地、腾空、救援及检查点规则。物理使用固定120Hz步长，相机平滑跟随，双人使用独立相机。`world.js` 绘制道路、土坡、桥墩和主题场景，`game.js` 装配输入、AI、道具与比赛流程。

运行 `npm test` 检查几何、道路框架、完整驾驶、低速圆环、飞跃特技、救援和计圈。

浏览器测试需要 Python Playwright 和 Chromium。启动服务器后运行：

```sh
npm run test:browser
npm run test:layout
npm run test:ai
```

可用 `KART_BROWSER_PATH` 指定已有Chromium，`KART_TEST_URL` 指定游戏地址，`KART_TEST_OUTPUT` 指定驾驶回归截图目录（默认 `/tmp/kart-rush-test`）。布局验收覆盖1920×1080、1440×900、1280×720、960×540、844×390、390×844及连续缩放。`test:ai` 通过真实比赛系统检查十二条赛道中八辆AI的完赛。功能回归还检查30／60／144Hz驾驶一致性与上下层交互隔离。完整圈测试通过真实驾驶步进加速执行，截图与键盘操作检查另行覆盖可读性和可操作性。
