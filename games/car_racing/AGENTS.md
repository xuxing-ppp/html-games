# 街机赛车

本项目同时遵守项目根目录的 [AGENTS.md](../../AGENTS.md) 的通用要求；以下记录赛车特有的约定。

## 美术与布局

- 使用明快的街机竞速风格，以赛车号码、斜切色块、贴纸、棋盘旗和弧形仪表等元素组织界面。
- 车与赛道占主要画面，赛前配置分组，出发入口明确。
- 主页面随窗口宽高自动适配，不出现整页横向或纵向滚动；主要内容和关键操作完整落在窗口内。
- 保留键盘驾驶与本地双人分屏，窄屏支持菜单浏览；不能因适配而丢失配置或比赛状态。

## 运行与验收

- 保留当前本地服务启动方式：使用启动／关闭脚本或 `npm run dev`、`npm run stop`；不要改成要求直接双击 HTML。具体说明见 README.md。
- 布局验收至少覆盖 1920×1080、1440×900、1280×720、960×540、844×390、390×844，以及连续缩放窗口。
- 核心界面重点检查赛道配置、出发入口和双人 HUD，确认两位玩家的信息与操作提示均可读、无遮挡。
- 规则改动按范围运行 `npm test`；界面与驾驶改动结合 `npm run test:browser`、`npm run test:layout`、`npm run test:ai` 及相关专项测试验证。浏览器测试需先启动游戏服务，环境参数见 README.md。
