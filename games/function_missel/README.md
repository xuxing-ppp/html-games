# 函数导弹

直接双击本目录的 **index.html**，在现代桌面浏览器中打开即可离线游玩。无需安装依赖、本地服务器或联网；请保留 `web/` 和 `sound/` 文件夹。

## 玩法与操作

- 主界面配置真人数、AI 数与难度，总人数为 2–8 人；默认 1 真人与 3 AI，也可纯 AI 观战。
- 输入 `f(x)` 后实时预览，系统自动添加常数 C，使弹道经过当前玩家。点击发射或按 Enter，导弹沿曲线向左右两侧前进。
- 每人 3 点生命，每次命中损失 1 点。导弹贯穿玩家，碰到掩体停止并挖出半径 0.6 的缺口。最后存活者获胜。
- 每回合可射击或移动；选择移动后点击合法位置，移动会结束回合，不能连续两回合移动。位置须避开掩体，且距离其他存活玩家至少 3 单位。
- 真人每回合 60 秒，到时自动发射当前有效函数，无效则跳过。暂停、返回主界面或打开帮助／设置时冻结对局。
- 设置可调整音量和坐标显示。函数示例可插入后编辑；设置会尽可能记忆在浏览器中。关闭页面不保留当前对局。
- 公式框外可按 P 暂停，Esc 返回主界面，结算时 R 重开。所有主要操作均有按钮；完整规则可在帮助中查看。

支持 `x`、`+ - * / **`、括号、`pi`、`E`，以及 `sin cos tan asin acos atan sinh cosh tanh exp log ln sqrt abs`。乘法须写 `*`，幂写 `**`。

## 维护与验证

- `web/core.js`：表达式白名单解析、弹道、碰撞、地图生成与 AI。
- `web/render.js`：坐标战场绘制与输入坐标换算。
- `web/app.js`、`web/style.css`：界面、状态切换、计时、音效与布局。
- 逻辑回归：在本项目目录执行 `node --test tests/web/*.test.cjs`。
- 浏览器回归：在 `html_games` 项目根目录执行 `python3 tests/html_games_browser.py` 或 `python3 tests/html_games_extended.py`，需要 Playwright 和 Chromium；可用 `PLAYWRIGHT_BROWSERS_PATH` 指定浏览器缓存。这些是开发测试工具，游戏运行不依赖 Python。

项目只维护 HTML／JavaScript 版本，旧 Python 实现及其依赖已移除。

## 显示版本

标题页与 Games 大厅共用本目录 `version.js`。修改时直接编辑引号内的版本数字。复制游戏时请一并保留此文件。版本维护方法见项目根目录的 [README.md](../../README.md)，显示版本与存档格式独立。
