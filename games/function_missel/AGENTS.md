# 函数导弹

本项目同时遵守项目根目录的 [AGENTS.md](../../AGENTS.md) 的通用要求。

- HTML 为默认入口，保留双击 index.html 离线运行，无服务器、联网或安装依赖。
- 保持弹道测绘台风格：深蓝坐标战场、橙红弹道和仪器控件。战场为主体，主界面配置沿战场边缘组织。
- 保留 2–8 人、本地多人、纯 AI 观战、三档 AI，以及既有生命值、回合计时、移动限制、弹道碰撞与掩体破坏规则。
- 函数输入使用白名单语法树解析，不执行输入代码；保留实时预览、自动偏移、双向发射和现有函数／常量支持。
- 返回主界面、暂停及打开帮助／设置时冻结对局；窗口变化不重置对局，公式输入与快捷键不得冲突。
- 逻辑改动运行 `node --test tests/web/*.test.cjs`；界面与离线操作按范围在 `html_games` 项目根目录运行 `tests/html_games_browser.py`、`tests/html_games_extended.py`，并实际查看画面。
