# 楚河行 · Xiangqi: Beyond the River

**一盏灯，三重山。借河拆阵，落笔成招。**

双击顶层 `index.html` 即可游玩，无需安装、联网或运行服务器。推荐桌面浏览器，1280×720及以上。

- **开始游戏**：三派任选，三章36程；第一章完成第三程后独立择进阶，前两章首领后继续升阶。
- **练习**：八门固定步骤的基础课程，自动配好门派与牌组，可看示范、上一步、重试和返回目录。
- **继续游戏**：继续当前旅程。

路线图沿虚线自下而上：只可前往连线相接的下一程。节点只显示地点类型，进入战斗后才揭晓场地和具体目标。普通战斗与任务战斗使用同一标记；精英种类仍未知。地图可在自身面板中纵向滚动，右侧“望山”和“回到当前”可快速定位。朱圈记录来路，虚圈标明当前可走节点。

侠与命灯共用生命、护盾，相隔最多三格。每回合行步一格或迁灯两步，共用一次普通行动。点击侠或命灯选择移动，再点同一个取消，点另一个直接切换。楚河／汉界在两岸之间占独立视觉间隔，木桥连接两岸；河道不额外增加棋盘格数。红区表示当前伤害位置；悬停格子查看来源，点敌棋展开蓝箭、落点、伤害与后续危险。右侧可逐步预演，或切换“全览”。

白菱是侠客的破绽出手位；金圈是阵眼；金线表示有效协作。白菱和金线在选中相关敌棋时展开，准备招式也会显示破绽。点击符号或“玩法帮助”可查看简短规则和单棋盘的逐步动画示范；支持暂停、前后步进、重播与返回目录。

六条进阶：剑的连影／渡江，掌的借壁／引河，指的蓄印／截势。心法保证进入首回合五张手牌，仍需付费打出。第三程后的悟道确认前可反悔进阶选择；营地是可选分支，只用于调息或磨剑；每次进阶可免费删一牌，也可保留。第一章首领后每回合4气，第二章首领后每回合抽6牌。武学面板可随时试演当前阶位的连招。

灵台以小灯座表示：命灯停驻至玩家回合结束，下回合额外获得1气，每座每战一次。点灵台在右侧查看用途；点“涨潮”或“移河”在右侧查看本次具体后果和位置，不会打开通用教学。

战斗中悬停卡牌即可显示完整效果、当前费用和已生效的额外伤害；鼠标可移进说明框继续阅读或滚动，短暂路过其他牌不会立即换掉说明。气力不足的牌也能查看，键盘聚焦同样可读。奖励选卡、商店、事件选牌和牌库直接在卡面显示全文，便于比较；升级后的卡显示实际效果。右上角 ⓘ 仍可固定打开详情。手牌下方不再重复显示效果；当前增伤、减费显示在资源区，落点预览仍显示资源变化和预计失血。

场地的3点伤害有明确来源：第一章涨潮每三回合一轮，提前一回合标出岸格，于预告回合结束时结算；荆棘只在进入时伤3；象的镇地按预告区域与时机结算。伤害浮字与记录会标出来源。

三章分别侧重渡口涨潮、机关物件与悬空移河。18个可变尺寸战场；破墙可毁、滚石可推、爆符伤4、灵台一次返气。夺渡、破枢、撤离任务也允许清场获胜。

选中身法牌后点灯，可放下待出的牌并切换到普通迁灯；选中攻击或身法牌时点侠，可取消出招，不消耗牌或气。推拉、易位等明确支持命灯的卡牌仍按有效目标正常使用。

18类事件与宝匣提供资源取舍；宝匣可选一件行器或35金。营地可绕行，选择休息还是冒险由路线决定。奖励、营地、商店与事件页的标题、选项、按钮整体横纵居中，较长内容仅在面板内滚动。

操作集中左侧，右侧看敌情。Esc取消选择、收起敌情或关闭面板；暂停菜单可切换常速／快速、减少动画。动画中可“快进本回合”。声音设置可分别调整配乐和音效。

## 快战与变局 · 2026-10-22

- **出手更快**：常速出牌等待由550毫秒降到160毫秒；敌方攻击前后等待由850毫秒降到300毫秒。暂停菜单仍可切换快速或减少动画。
- **每战一次免费变招**：把整手牌放到弃牌堆，先从其余牌抽回等量手牌；不会立即抽回刚换掉的牌。牌堆与已有弃牌不足时禁用，不损失手牌，不增加牌数、不回复气势。
- **普通战三种变局**：猎首击败金圈阵眼就赢；火攻增加三枚可引爆的爆符，敌我均受影响；双雄仅保留两敌，生命为新普通战标准的1.2倍。进入战斗后在棋盘标题和右侧直接说明规则。
- **减少磨血与赶路**：普通战敌人基础生命降为原来的80%（向上取整），攻击不变。安全时侠与灯一起前移一格，保留至少三个普通移动落点，且不贴敌或贴爆符。精英、首领、任务战及教学不套用此变局与血量调整。
- 试招条件和进度可从暂停菜单的“棋局记录”查看；原本进行中的战斗不重置，下次进入普通战即应用改版。

## 灯火新章 · 2026-10-22

- **命灯三诀**：战斗左侧操作区可释放，每战三选一、共用一次，消耗2势。照夜获得5护盾；问心抽2牌；续焰获得1气。与凌波、绝技竞争势资源，不消耗普通行动。护盾仍按原规则在下回合开始时清除；抽牌仍受10张上限约束。
- **江湖试招**：每战揭晓一种额外挑战：5回合内速胜、触发打断／破阵、或渡河／碰撞／打断／破阵中完成两种。完成后还需赢得战斗才得8金，每章累计最多24金；失败无惩罚，不影响正常战利品。棋局记录显示条件与进度，胜利页显示结果。
- **青绿山水**：新的分层山峦、薄雾、飞鸟、山石纹理、命灯辉光与河流动效；系统偏好减少动画时自动静止。

版本6存档可继续使用。已在进行中的旧战斗没有试招，下一战起出现；教学不启用新机制，避免干扰基础规则学习。

## 基础教学与侧栏 · 2026-10-23

帮助与练习保留独立入口。帮助用于局中查阅；练习包含行步与出牌、命灯与防护、敌方预告与套路、地形与棋具、河界与涨潮、破绽与打断、金线与破阵、势与心法八门课程。每课固定门派、手牌、抽牌顺序与目标，只允许当前要求的操作，查看卡牌和敌情不受限制。选派页的“基础练习”同样进入这份目录。

规则说明、练习和动画共用固定例子，实际调用出牌与敌方回合结算。帮助示范在单张纸偶棋盘上展示移动、出招和结果；减少动画时逐帧切换。帮助中还可按需查阅任务、特殊棋具与进阶，以及绝技和三种灯诀的真实势消耗。关闭帮助恢复原有选牌、敌情和手牌滚动位置；练习返回时恢复进入前的页面或对局。

玩家操作全部集中左侧：资源与武学、变招、双列手牌、移动与招式、命灯三诀、预计失血、结束回合。手牌独立滚动，操作区固定。右侧保留敌情、预演、场地后果和当前战斗规则，不再常驻通用教学或试招说明。试招奖励、正式玩法和版本6存档格式保持原样；练习进度仅保留在本次练习中。

## 教学对照与标记说明 · 2026-10-23

炮击教程现在实际比较留在炮线、移走且没有目标、离线但仍邻近命中目标三种情况。砲必须先隔着炮架命中另一个棋子，才产生以目标为中心的十字溅射；没有命中目标就没有溅射。图示标出炮架与目标，结算对比会保留在本课中；重置局面对比是明确操作，不消耗正式对局资源。

河界课增加走桥、非桥涉水、轻功、同回合重复渡河、新回合得势和迁灯费用对比，并说明守岸失阵、涨潮与移河。破绽课用同一张弹指对比普通命中和白菱打断，命灯始终原地不动，实际失血分别为5和0。金线课在同一位置用同一张牌攻击同一枚砲，士护阵时伤3，拉士断阵后伤5。

势与心法扩为两回合、14步的综合练习，实际使用破阵、渡河、打断、心法碰撞得势，验证每回合最多获得3势、最多储存4势，再依次使用灯诀、凌波与绝技。界面显示当前势和本回合累计得势，区分储存上限和回合上限。

移动箭头删除重复终点，保证末段方向正确；攻击路线停在实际命中点。棋盘下方的系灯限制改为“侠与命灯相距几格（最多3格）”，没有命灯时不显示；势资源增加文字标签。

当前规则存档版本为6，键名 `xiangqi-beyond-the-river-v6`。已有版本6旅程可继续原来的21程路线与营地进阶；新开一局体验36程、可选营地和独立悟道。更早版本的数据保留、不提供旧版入口。自动保存依赖浏览器本地存储，换浏览器或移动目录可能影响续局。存储不可用时仍可游玩，刷新后无法续局。

## 纸偶戏台界面

墨黑、灯金与纸偶轮廓贯穿标题、选派、路线、战斗和结算。战斗保留左侧双列手牌、中央等比棋盘、右侧敌情三栏；棋盘按中央实际可用空间适配。手牌滚动后可继续悬停阅读，缺气时同样可读，剧情和卡牌效果没有删减。

`tests/card_reading_ui.py` 与 `tests/final_smoke.py` 支持通过 `XQ_BROWSER_PATH` 复用已有 Chromium。

`tests/layout_paper_ui.py` 验证三栏棋盘占满可用空间，以及十张手牌滚动后逐张阅读；同样支持 `XQ_BROWSER_PATH`。
