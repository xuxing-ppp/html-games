# 大明县令

- 维护原生JavaScript、CSS与index.html，无框架、构建或运行依赖，支持双击离线与静态部署。
- 修改前参考 docs/MAINTENANCE.md 与作者用 docs/MYSTERY.md。规则放 engine.js，保存校验放 storage.js；DOM点击不得自行判题或改裁定。
- 仅维护当前 scene-mystery 格式。存档键 jingshui.magistrate.v1；不恢复旧档入口、迁移、归档、导出或旧玩法。
- 前三案线性，第四案有限探索，三轮复审沿用配对、排序与对照。没有经费、行动耗时或倒计时。随手记可选，不作为胜负条件。
- 以场景、人物和下方对白为日常主体，整理时才切案头。保留原文、内部滚动、阅读位置、三档字体大小、减少动态效果及明确返回路径。
- 私人笔记不判对错；错误整理不扣资源或次数，不自动公布答案。提示由玩家逐级请求，固定事件日期不随查访顺序变化。
- 史料与创作说明集中在案卷，不在正常剧情反复强调虚构。历史人物不替玩家解题或担保翻案。
- 全部场景统一为淡设色水墨，保留墨线、纸色和留白，不用写实图套色替代重绘。同一县衙保持白墙灰瓦围合院落、石铺庭院、木廊柱及同一院门，不因横竖版或昼夜改变建筑。人物与背景须用同一写意概括程度，不能局部细画皮肤、发丝或衣服纹样。水墨层次靠线条、淡墨与留白，不用密集黑点、做旧噪声和满屏斑驳表现画风。各场景分别安排明暗，不因统一画风而全局提亮；夜景必须在缩略图中也能认出是夜晚。
- 任期主角32–35岁，有薄髭和短颏须，以核仓图为参考。多年后保留脸型再自然衰老。见 assets/MYSTERY.md。
- 修改规则或内容后运行 node --test tests/engine.test.mjs tests/content.test.mjs tests/art.test.mjs tests/endings.test.mjs。布局修改实际运行 tests/mystery-browser.py 并查看画面，覆盖桌面、短横屏、手机和三档字号。
- GitHub Pages 直接从仓库加载游戏源码和运行资源。更新原图后运行 python3 tools/prepare_assets.py 生成 WebP 和校验清单。
- 不留下临时依赖、截图、报告或缓存。自动通关不能代替普通新玩家理解验证。

- v1.1有21题、四条可略过支线。分支改变材料取得时机与回应，常规调卷取得独立材料后汇合；不以护送危险推定幕后主使。新内容格式 version:3/contentRevision:mystery-expanded，旧进度确认前不覆盖。
