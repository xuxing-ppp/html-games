# 大明县令 · 净水县

嘉靖四十年（1561），你来到浙江净水，接任县令。从吴秋娘的一张催粮单开始，跟随人物和故事查清四件相连的案子，在最后复审中解释粮食、凭据与各人的责任。

**当前版本见 [version.js](version.js)。**

## 开始游玩

从 GitHub Pages 的游戏大厅进入《大明县令》，选择「开始游戏」或「继续游戏」。本地开发可直接双击 `index.html`。

## 怎样办案

先读场景，弄清谁遇到了什么事；再整理眼前的少量材料，出示结果，看到实际处置。对白使用自然白话，以人物的处境和交锋推进故事；开场介绍县令身份、县境和必要称呼。三种整理方式首次出现时给一句轻提示，操作后收起。资料与提示随时可看。

三种整理方式：

- 归类：选纸签，再选归属。
- 排序：用上移、下移调整先后。
- 对照：两份文书各选一项，再出示结果。

材料按当前问题摆在案头，可随时查看原文。错误有具体说明，允许不限次数重试；「请求提示」由浅入深给出三层帮助，不自动公布答案。

前三案按故事推进，第四案才开放账房、驿舍、米行三个调查点，可选顺序、可补访，不必扫完所有地点。随手记完全可选。游戏没有查案经费、行动耗时或期限管理，日期随场景推进；文书所记事件日期与文书制作日期仍需分清。

复审沿用相同的整理方式。有限裁定或交易会先说明将放弃哪些追查，再明确确认；小游戏误答不会造成坏结局。裁定后会展示追缴、退赔及人物去留。完整成功后的为官或著述道路，由途中五处生活选择自然形成，没有结尾的路线选择按钮。

## 案卷、舆图与阅读

「案卷」收录已证案情、材料、人物往来、剧情回顾与史料笺。「帮助与设置」放操作说明、教学回放、动态效果、声音、存档说明和重新开始，不重复放案情资料。

查阅页面可逐层「返回」，也可「关闭」回到原场景。Esc优先返回上一级，在根页面关闭。返回保留材料摆放、选择、阅读位置与入口焦点。

人物署名旁的「人物资料」可查看身份。正文中带点状下划线的词可点击解释，不再在对白下方另列词语；返回保留阅读位置。选择被长对白推到下方时，可点「查看选项」定位。

「字体大小」统一提供18、20、22像素三档，默认中号；选择单独保存。长文在阅读区内滚动。舆图参与到任、第一次出访、粮船航路和后期调查；地点列表与图上标签同步，可用按钮缩放、移动与复位。

海瑞、戚继光、胡宗宪在相应阶段与玩家交流。历史资料、书目和创作边界集中在「案卷 → 史料笺」，外部出处只在主动点击后联网。

## 保存

推进对白、移动签条、选择与整理结果自动保存在当前浏览器。只支持当前格式，不迁移或归档旧版进度。重新开始需确认替换当前有效进度。

换浏览器、换文件地址、清理浏览数据或使用无痕模式，可能无法继续原进度。若保存失败，游戏会明确提示，本次仍可继续。存档键为 `jingshui.magistrate.v1`，无需手工操作。

## 维护与验证

直接维护原生JavaScript、CSS和HTML，无框架、打包器或运行依赖。见 [维护说明](docs/MAINTENANCE.md)、[内容说明](docs/CONTENT.md) 和 [图片记录](assets/MYSTERY.md)。[作者案情表](docs/MYSTERY.md) 含全部谜底，建议游玩后阅读。

规则检查：

```
node --test tests/engine.test.mjs tests/content.test.mjs tests/art.test.mjs tests/endings.test.mjs
```

浏览器检查使用已有Python Playwright：`python3 tests/mystery-browser.py`。可通过 `MING_BROWSER_PATH` 指定Chromium，`MING_URL` 指向静态地址或本地入口。这些是维护工具，不是游玩依赖。

更新原图后执行 `python3 tools/prepare_assets.py`，生成 WebP 和校验清单。

浏览器验收覆盖流程、布局与正常动态效果，另需结合首次试玩观察玩家能否读懂线索、是否清楚下一步。
