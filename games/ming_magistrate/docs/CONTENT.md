# 内容、史料与创作边界

故事始于嘉靖四十年（1561）浙江净水。开场先介绍县令身份、县境、沈砚与眼前纠纷，再随剧情解释官粮、收据、里长、仓书和知府。

- 57个主线节点：到任、吴秋娘引子、四件相连案件、人物往来、五处生活选择和最终复审。
- 15个核心整理关：配对分类、排列先后、两份文书对照。每关只围绕当前问题处理少量记录。

- 前三案固定顺序；第四案账房、驿舍、米行三个地点自选先后，接受独立替代证明。随手记仅在后期出现，不作为结案条件。
- 海瑞因公短会、戚继光军需问答与回信、胡宗宪方面的公务来函和县里回复。每种交流有实际内容与可选回应。
- 三轮复审、四类明确裁定、判决执行、两条各五幕的完整成功后日谈；其他裁定三幕，明确未能追究的责任。
- 24篇离线史料说明、六主题与八种书目。

故事按场景分为有内容的对白、旁白和行动。每次推进应说明处境、问题或线索，避免一句话拆成多个无用点击，也避免把一整场铺成论文。原文负责核对细节，不能代替故事。无硬性字数门槛。

引子与正式案件共用同一套界面和规则，配对、排序与对照在第一案结束前依次出现。每种操作首次出现时，在材料旁给一句轻提示，实际操作后收起；其后依靠选中状态、放置目标与进度反馈。原文、案卷、前文与提示均按需打开，不作为推进条件。

## 文风与阅读

对白以自然白话为主，保留时代称谓。每场围绕人物眼下的诉求、顾虑与相互回应展开，用动作、停顿和具体处境承载情绪；允许温情、幽默与安静的段落，不将所有交流写成讲解或争吵。清楚交代因果，但不让旁白替玩家推理，也不以固定字数压缩对白。

文书按用途分笔调：账簿严整，供词保留当事人的说话方式，私人书信有人情与余味，公务往来体现分寸和压力。适量套话可以保留，关键日期、数量、田号、签押及证明范围须清晰，与场景、整理题相合。

只对仓书、里长、底联等确需解释的词提供文内点状下划线入口。同一段展示内容不重复标记同一词，正文没出现的词不另外列出。县令、官粮、收据等已通过情境讲明的常用词不反复加注。解释不提供未揭示案情。

人物署名为明确的“人物资料”按钮。长对白下的选择可由固定“查看选项”入口定位；正文、文书和结局在阅读区内滚动，主操作保持可达。

## 界面文案的取舍

普通场景只显示地点和标题。案头用一句话提出当前问题，操作方式交给控件、第一次的轻提示和即时状态。操作说明仅保留归类、排序、对照三行示意及提交入口，键盘操作折叠查看。

对白、材料、人物与结局保留有用的事实和情感。证据边界以具体见闻、日期和经手表达；重复的作者评语、无关假设与预先辩解删去。创作说明简述故事性质，史料文章集中讲实际背景与出处。

## 历史与创作

净水县、主角、地方人物、粮案、文书、裁定与主角后日谈为创作。海瑞、戚继光、胡宗宪是真实人物，具体会面、问答与往来依时代位置编写，不冒作历史原文。说明集中在游戏「案卷 → 史料笺 → 创作说明」，不在正常剧情和结局反复插入。

海瑞以嘉靖四十年淳安知县经历安排；戚继光对应当年浙江战事；胡宗宪通过公务来函介入县外压力，不直接审断主案。真实人物有自己的立场，不替玩家揭谜，不提供翻案担保。唐顺之已于1560年去世，不安排本年相见。

沿用《明史》《明世宗实录》《大明律》《海瑞集》《纪效新书》《筹海图编》《嘉靖浙江通志》《天工开物》的离线介绍和定位。《天工开物》晚于故事，仅作后世延伸阅读。版本、卷篇和出处在史料笺提供，主动点外部链接才联网。

计量、县官权限、复核及刑罚程序有所简化，不做制度考试。推理只依游戏内已出现材料。多年后官历、著作与声名不取代真实人物功绩，也不伪称史籍记有此人。
